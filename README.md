# Employee Management Frontend

Frontend application for managing employee records, built with HTML, CSS, and JavaScript.

## Features

- View employee records
- Add new employees
- Manage employee information
- Responsive and user-friendly interface
- Integration with Employee Management REST API

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API

## Prerequisites

Before running the project, make sure you have:

- A modern web browser such as Chrome, Edge, or Firefox
- A code editor such as Visual Studio Code
- Employee Management Backend API running locally
